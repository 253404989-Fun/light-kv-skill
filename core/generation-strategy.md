## 1. Purpose

Select a mature visual solution before exploring a new one.

Apply `R-REF-01`, `R-CAP-01`, `R-GEN-01`, `R-STR-01`, `R-RIGHTS-01`, and `R-FAIL-01`.

## 2. Reference First

After parsing the Brief:

1. Load the Core Aesthetic Parents catalog.
2. Select the closest aesthetic parent for quality calibration.
3. Load the Generative Reference catalog.
4. Match concrete structural needs to Reference metadata.
5. Read relevant Failure entries before confirming the direction.
6. Select Adapt, Recompose, or Explore.

Do not begin with random prompt invention.

## 3. Use the Library by Role

### Core Aesthetic Parents

Use Core Parents to judge:

- overall restraint;
- visual atmosphere;
- negative-space quality;
- scale and spatial relationships;
- whether the direction belongs to LIGHT KV.

Do not use Core Parents as literal templates or sources of copy.

### Generative Reference Library

Use Generative References to retrieve:

- composition structure;
- light behavior;
- spatial mechanism;
- color architecture;
- typography zones.

For every selected Reference, name its contribution and its prohibited transfer.

### Failure Library

Use Failure entries only to detect risks and prescribe corrections. Never select a Failure entry as a positive generation parent.

### Pending Review

Exclude Pending entries from default retrieval. Use one only after explicit human approval and record the approval.

## 4. Choose Adapt First

Choose `Adapt` when one mature Generative Reference can solve the Brief.

Record:

- the primary Reference ID;
- at least two relationships to preserve;
- brand, copy, canvas, and local details to change;
- all visible source elements that must not transfer.

Changing only colors or copy is not enough if the target canvas requires a new spatial composition.

## 5. Choose Recompose When Necessary

Choose `Recompose` only when one Reference cannot satisfy the Brief.

Assign one dominant structural parent. Give every additional Reference a limited role, such as:

- Reference A: spatial structure;
- Reference B: light behavior;
- Reference C: color relationship.

Do not combine References as equal layers. Do not let recomposition increase clutter or erase negative space.

## 6. Gate Explore

Consider `Explore` only after documenting:

- which Core Parents were checked;
- which Generative References were checked;
- why Adapt cannot solve the Brief;
- why Recompose cannot solve the Brief.

Continue to obey the Visual Constitution, Copy Whitelist, Canvas Lock, and Failure Library. Explore does not authorize strange forms, literal technology symbols, or extra copy.

## 7. Respect Reference Rights

The public catalogs are metadata-only design abstractions and do not include the private source images from which the initial vocabulary was developed. Treat any user-supplied visual asset according to its recorded rights and allowed-use fields. If rights are unknown, limit use to visual analysis.

Do not:

- reproduce a Reference as final artwork without permission;
- reuse its Logo, copy, watermark, or credited identity;
- imply ownership or publication rights;
- treat an analysis crop as a production asset;
- attempt to reconstruct or retrieve a private source image from a metadata card.

Extract relationships, not protected surface expression.

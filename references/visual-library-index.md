# LIGHT KV Public Visual Library

This release contains metadata-only visual Reference cards rather than source artwork.

| Library | Count | Purpose |
| --- | ---: | --- |
| Core Aesthetic Parents | 2 | Define the highest aesthetic boundary |
| Generative Reference Library | 4 | Provide adaptable structure, light, material, and color mechanisms |
| Failure Library | 8 | Detect and correct low-quality technology-visual patterns |
| Pending Review | 1 | Hold a useful but conflicting optical-aperture pattern |

## Use order

1. Calibrate with one Core Aesthetic Parent.
2. Retrieve the smallest sufficient Generative Reference set.
3. Check relevant Failure entries.
4. Exclude Pending Review by default.
5. Apply Copy Whitelist and Canvas Lock throughout.

Metadata cards describe reusable relationships; they do not authorize reconstruction of any private source image. For optional owned or licensed images, follow `reference-profile-guide.md`.
